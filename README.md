Mini Project: Program Data Mahasiswa

Deskripsi
Program Data Mahasiswa adalah aplikasi sederhana berbasis Java 
yang digunakan untuk memasukkan, menyimpan sementara, 
dan menampilkan data mahasiswa. 
Program ini juga menentukan status kelulusan berdasarkan nilai yang diperoleh mahasiswa.

# Tujuan
Mini project ini dibuat untuk menerapkan konsep dasar pemrograman Java, 
khususnya penggunaan variabel, tipe data, input pengguna, 
percabangan, perulangan, class, object, dan method.

# Fitur Program
- Memasukkan nama mahasiswa.
- Memasukkan NIM mahasiswa.
- Memasukkan nilai mahasiswa.
- Menampilkan data mahasiswa.
- Menentukan status kelulusan mahasiswa.
- Mengelola minimal tiga objek mahasiswa.

# Komponen Pemrograman
- Variable: Menyimpan nama, NIM, nilai, dan jumlah mahasiswa.
- Data Type: Menggunakan String, double, dan int.
- Scanner: Menerima input dari pengguna.
- If/Else: Menentukan status kelulusan.
- Loop: Mengulang proses input dan menampilkan data.
- Class: Menggunakan class `Mahasiswa` dan `Main`.
- Object: Membuat objek mahasiswa.
- Method: Menggunakan `tampilkanData()` dan `cekKelulusan()`.

# Ketentuan Kelulusan
- Nilai 60 atau lebih: "LULUS"
- Nilai di bawah 60: "TIDAK LULUS

# Teknologi
- Bahasa pemrograman: Java
- Input dan output: Terminal atau Command Prompt
- Repository: GitHub

# Cara Menjalankan Program
1. Pastikan Java Development Kit (JDK) sudah terpasang.
2. Unduh atau clone repository ini.
3. Buka terminal di folder yang berisi file `Main.java`.
4. Kompilasi program dengan perintah:
   "javac Main.java"
5. Jalankan program dengan perintah:
   "java Main"
6. Masukkan nama, NIM, dan nilai untuk tiga mahasiswa.
